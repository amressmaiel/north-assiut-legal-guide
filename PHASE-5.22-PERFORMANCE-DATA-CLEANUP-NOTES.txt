المرحلة 5.22 — تحسين الأداء وتنظيف البيانات
================================================

تمت إضافة مركز مستقل لتحسين الأداء وصيانة التخزين المحلي داخل المنصة، ويعمل كأداة إدارية قبل النسخ الاحتياطي أو العرض الرسمي.

المكونات المضافة:
- assets/js/performance-maintenance-center.js
- زر جديد في القائمة الجانبية: تحسين الأداء والصيانة
- أنماط CSS مخصصة داخل assets/css/main.css

الوظائف:
1. فحص حجم التخزين المحلي LocalStorage.
2. عرض أكبر عناصر التخزين.
3. تحديد العناصر المؤقتة والكاش.
4. تنظيف العناصر المؤقتة.
5. تقليل السجلات القديمة إلى حد آمن.
6. ضغط مفاتيح JSON بإزالة المسافات الزائدة.
7. إنشاء فهرس بحث خفيف لا يكرر النصوص القانونية الكبيرة.
8. تصدير تقرير فحص الأداء بصيغة JSON.
9. سجل محلي لعمليات الصيانة.

ملاحظات مهمة:
- لا يتم حذف بيانات أساسية تلقائيًا.
- التنظيف يستهدف المفاتيح المؤقتة فقط.
- ضغط JSON يحافظ على نفس البيانات مع تقليل الحجم.
- يفضل تشغيل هذه المرحلة قبل النسخ الاحتياطي الكامل.
