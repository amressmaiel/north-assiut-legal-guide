====================================================
PHASE 5.24 — مركز الإعدادات العامة المتقدم
====================================================

تم تنفيذ مرحلة مركز الإعدادات العامة المتقدم كلوحة مؤسسية موحدة لإدارة إعدادات المنصة من داخل الواجهة بدل تعديل الكود.

المزايا المضافة:

1) هوية المنصة:
- اسم المنصة الكامل والاسم المختصر.
- اسم المساعد القضائي سَنَد.
- الجهة / النيابة.
- نصوص التوجيه والإشراف والإعداد والتطوير.
- مسارات الشعار وصورة سَنَد وصورة السيد المستشار.

2) الربط والخدمات:
- إعداد روابط Workers من شاشة واحدة:
  * AI / Gemini proxy
  * Auth API
  * Realtime Communication
  * Case Files
  * Case Sharing
  * Legal Content
  * Institutional Reports
  * Backup & Restore
  * Maintenance / Security
- اختبار روابط الخدمات.
- نسخ ملخص الربط.
- حفظ الروابط فقط دون أي أسرار أو مفاتيح API.

3) السياسات:
- سياسة التخزين local-first / cloud-sync / local-only.
- سياسة المزامنة.
- حدود ملفات الوقائع المحلية.
- سياسة المرفقات.
- تذكير النسخ الاحتياطي.
- سياسات التدريب والاجتماعات وروابط الضيوف.
- سياسات سَنَد والإجابة والحوار الصوتي.

4) الوحدات والواجهة:
- تشغيل وإيقاف وحدات المنصة من الواجهة.
- إعداد الثيم وكثافة العرض والحركة.
- وضع العرض الرسمي.
- وضع البيانات التجريبية.
- رسالة صيانة أعلى المنصة.
- سلوك القائمة الجانبية وبوابة الضيوف.

5) الأمان والخصوصية:
- عزل صفحة الضيوف.
- إخفاء أدوات الإدارة عن غير المصرح.
- تسجيل الأحداث الحساسة.
- إلزام مراجعة المحتوى القانوني قبل النشر.
- وضع الأمان قبل العرض الرسمي.
- منع حفظ أي Secrets داخل Frontend.

6) أدوات الإدارة:
- تصدير الإعدادات.
- استيراد الإعدادات.
- تصدير لقطة إعدادات كاملة.
- سجل محلي لعمليات تعديل الإعدادات.
- توافق مع المفاتيح القديمة مثل Auth API وRealtime Communication.

ملفات تم تعديلها أو إضافتها:
- config/app-config.js
- assets/js/admin-settings.js
- assets/css/main.css
- index.html
- platform.manifest.json
- backend/cloudflare-worker-platform-settings.js
- backend/d1/migration-5.24-platform-settings.sql

ملاحظات أمنية:
- لا تحفظ هذه الشاشة أي مفاتيح سرية.
- أي مفاتيح Gemini أو Tokens يجب أن تبقى داخل Cloudflare Secrets.
- الروابط المحفوظة في الواجهة هي روابط تشغيلية فقط.
