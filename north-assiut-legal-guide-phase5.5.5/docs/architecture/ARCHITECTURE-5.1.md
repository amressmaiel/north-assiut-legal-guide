# معمارية المرحلة 5.1 — التحول المؤسسي

## الهدف

تحويل المشروع من واجهة غنية واحدة إلى منصة Modular مؤسسية قابلة للإدارة والتوسع.

## مبدأ مهم

المرحلة 5.1 لا تكسر المسارات الحالية ولا تنقل الملفات التشغيلية الأساسية من أماكنها حتى لا تتعطل GitHub Pages.
بدلًا من ذلك أضيفت طبقة تنظيمية جديدة:

- `config/app-config.js`
- `core/module-registry.js`
- `core/runtime/platform-boot.js`
- `modules/*`
- `docs/*`

## الحدود المعمارية الجديدة

- `core/`: نواة المنصة وسياسات التشغيل والأمان والتخزين.
- `modules/`: توصيف وحدات المنصة وحدودها.
- `config/`: إعدادات الهوية والتشغيل غير السرية.
- `backend/`: Cloudflare Worker الحالي.
- `docs/`: توثيق معماري وتشغيلي.
- `data/`: بيانات القوانين والمواعيد.
- `assets/`: ملفات التشغيل الحالية للواجهة.

## ما الذي لم يتغير؟

- لم يتم تعديل Cloudflare Worker.
- لم يتم نقل ملفات القوانين.
- لم يتم تغيير طريقة تحميل سَنَد أو غرفة تحليل الواقعة.
- لم يتم فرض تسجيل دخول أو تخزين مركزي بعد.

## ما الذي أصبح جاهزًا؟

- فصل الهوية والإعدادات في ملف مركزي.
- سجل وحدات يصف كل Module ومسؤولياته.
- مسار واضح للانتقال إلى لوحة إدارة وصلاحيات وBackend مؤسسي.
