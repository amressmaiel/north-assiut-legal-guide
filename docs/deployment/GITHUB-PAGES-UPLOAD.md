# رفع نسخة المرحلة 5.1 على GitHub Pages

1. فك ضغط الملف.
2. افتح مجلد `north-assiut-legal-guide-phase5.1`.
3. ارفع محتوياته إلى جذر Repository الحالي.
4. اختر Replace عند التعارض.
5. انتظر تحديث GitHub Pages.
6. نفذ تحديث قوي للمتصفح: `Ctrl + F5`.

لا يوجد تعديل مطلوب في Cloudflare Worker في هذه المرحلة.
