# iOS TestFlight Checklist

## قبل فتح Xcode
- [ ] آخر نسخة مرفوعة على GitHub.
- [ ] `npm install` تم بنجاح على Mac.
- [ ] `npm run ios:doctor` لا يظهر أخطاء.
- [ ] `npm run ios:add` تم لأول مرة فقط.
- [ ] `npm run ios:sync` تم بعد آخر تعديل.

## داخل Xcode
- [ ] Bundle Identifier صحيح.
- [ ] Team مضبوط.
- [ ] Version و Build مضبوطين.
- [ ] App Icons مضافة.
- [ ] Splash Screen مقبولة.
- [ ] Privacy Manifest مضاف عند الحاجة.
- [ ] التطبيق يعمل على iPhone حقيقي.

## اختبار وظيفي
- [ ] تسجيل الدخول.
- [ ] مركز القيادة.
- [ ] سند.
- [ ] مكتبة القوانين.
- [ ] غرفة تحليل الوقائع.
- [ ] ملفات الوقائع.
- [ ] التدريب والاجتماعات.
- [ ] التواصل والإشعارات.
- [ ] وضع العرض الرسمي السينمائي.
- [ ] الروابط الخارجية والاجتماعات.

## قبل TestFlight
- [ ] لا توجد مفاتيح سرية داخل المشروع.
- [ ] لا تظهر رسائل Debug للمستخدم.
- [ ] البيانات التجريبية مضبوطة أو معطلة حسب العرض.
- [ ] تمت أرشفة التطبيق من Xcode.
- [ ] تم رفع Build إلى App Store Connect.
