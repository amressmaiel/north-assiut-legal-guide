# Android App Readiness Checklist

- [ ] Android Studio مثبت ويعمل.
- [ ] تم تنفيذ npm install.
- [ ] تم تنفيذ npm run android:add.
- [ ] تم تنفيذ npm run android:sync.
- [ ] التطبيق يفتح من Android Studio.
- [ ] الأزرار مناسبة للمس.
- [ ] الشريط السفلي لا يغطي المحتوى.
- [ ] الروابط الخارجية تفتح خارج التطبيق.
- [ ] الاجتماعات المرئية تفتح بشكل آمن.
- [ ] تسجيل الدخول يعمل عبر Auth API عند ضبط الرابط.
- [ ] وضع العرض الرسمي يعمل على شاشة الموبايل.
- [ ] ملفات النسخ الاحتياطي والتصدير تم اختبارها.
- [ ] لا توجد أسرار داخل الواجهة.
