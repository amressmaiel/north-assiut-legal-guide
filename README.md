# الدليل القضائي الذكي لأعضاء النيابة العامة

نسخة متعددة القوانين من المنصة، مع فصل الواجهة والتنسيقات والسكربتات وملفات البيانات.

## القوانين المتاحة

1. قانون الإجراءات الجنائية الجديد رقم 174 لسنة 2025 — 70 مادة تنفيذية تفصيلية.
2. قانون العقوبات المصري رقم 58 لسنة 1937 — 525 سجلًا قانونيًا من النسخة المراجعة والمختبرة.

## الهيكل

```text
index.html
assets/
  css/
  js/
  images/
data/
  laws-index.js
  laws/
    criminal-procedure-174-2025.js
    penal-code-58-1937.js
backend/
  cloudflare-worker.js
reference/
  penal-code-source/
```

## إضافة قانون جديد

1. تجهيز ملف بيانات مستقل داخل `data/laws/`.
2. تحميله داخل `index.html` قبل `data/laws-index.js`.
3. تسجيله داخل `data/laws-index.js` ضمن `window.LAW_MODULES`.
4. توحيد الحقول المعروضة مع `EXECUTIVE_FIELDS` أو إضافة محول للحقول داخل ملف القانون.

## سَنَد

سَنَد يبحث تلقائيًا داخل جميع القوانين المحملة محليًا، وليس القانون المفتوح فقط. الاتصال الخارجي يمر من خلال Cloudflare Worker لحماية مفتاح Gemini.

## المرحلة الأولى من تطوير المنصة الذكية
تمت إضافة:
- بحث موحّد في جميع القوانين المحملة.
- فتح أي مادة من نتائج البحث مع التحويل إلى قانونها تلقائيًا.
- زر «اسأل سَنَد عن هذه المادة» داخل صفحة كل مادة.
- أربعة أنماط لإجابات سَنَد: مختصر، تنفيذي، تفصيلي، تعليمي.
- عرض المواد المستخدمة في الإجابة كأزرار قابلة للفتح.
- اقتراحات متابعة ذكية بعد الرد.

## المرحلة الثانية: مساحة العمل الشخصية
- المفضلة والمجموعات تحفظ محليًا داخل المتصفح.
- آخر المواد المفتوحة تحفظ محليًا.
- مقارنة مادتين تعمل بين أي قانونين محملين.
- وضع القراءة المركزة يخفي عناصر الواجهة الثانوية مؤقتًا.

## المرحلة الثالثة — أدوات التنفيذ القضائي

تمت إضافة مركز أدوات تنفيذي مستقل داخل المنصة، ويضم:
- درع المراجعة الوقائية للإجراءات.
- حاسبة المواعيد والتنبيهات المبنية على مدخلات المستخدم.
- منشئ قوائم الاستيفاء حسب نوع الواقعة.
- مساعد مراجعة الاختصاص.

هذه الأدوات للمراجعة المساندة فقط ولا تُغني عن الرجوع إلى النصوص الرسمية والتعليمات المختصة والتقدير القضائي للملف.

تم إضافة قاعدة بيانات مستقلة للمواعيد القانونية، اختيار الإجراء، الحساب التلقائي، حالة الميعاد، السند القانوني، الحفظ المحلي، والطباعة والنسخ.


## المرحلة 3.2.2
تم تطوير حاسبة المواعيد بإضافة تصفية النظام القانوني، الأسئلة الديناميكية، زر فتح النص القانوني، وتحذيرات توافق فترة السريان.

## المرحلة 4.1 — سَنَد: غرفة تحليل الواقعة
تمت إضافة غرفة تحليل مستقلة للحوار المتدرج حول الواقعة، مع أسئلة استكمال، تكييفات محتملة، أسانيد قابلة للفتح، استيفاءات وتنبيهات، وتقرير مراجعة داخلي. تم تجهيز واجهة المرحلة التالية لرفع المستندات والصوت دون تفعيل إرسال الملفات قبل بناء طبقة الحماية.

## المرحلة 4.2.1 — الحوار الصوتي المباشر

## Phase 4.4
تمت إضافة تقرير تحليل الواقعة الاحترافي القابل للنسخ والطباعة والحفظ المحلي.


## المرحلة 4.5 — ربط التقرير بالأدوات التنفيذية

تمت إضافة بطاقة أدوات تنفيذية مقترحة داخل نتيجة تحليل الواقعة وداخل التقرير الاحترافي، مع ربط مباشر بحاسبة المواعيد، درع المراجعة الوقائية، منشئ قوائم الاستيفاء، مراجعة الاختصاص، وتنبيهات الدليل الرقمي بحسب مؤشرات الواقعة. لا توجد تعديلات مطلوبة على Cloudflare Worker.

## المرحلة 4.6 — قوالب تحليل متخصصة حسب نوع الواقعة

أضيفت طبقة قوالب متخصصة داخل غرفة تحليل الواقعة، بحيث يختار سَنَد تلقائيًا قالبًا مناسبًا مثل: الاعتداء على النفس، جرائم الأموال، التزوير، الدليل الرقمي، أو سلامة الإجراء. تظهر القوالب داخل نتيجة التحليل والتقرير الاحترافي، وتشمل عناصر الفحص والأسئلة الفاصلة والاستيفاءات والتنبيهات.


## المرحلة 4.7 — قوالب جرائم إضافية متخصصة

أضيفت مجموعة جديدة من قوالب التحليل المتخصصة داخل غرفة تحليل الواقعة، لتوسيع قدرة سَنَد على التعامل مع أنواع وقائع أكثر شيوعًا في العمل اليومي.

القوالب الجديدة تشمل:

- جرائم المخدرات: حيازة، إحراز، تعاطٍ، اتجار، تحريز، تقرير المعمل الكيماوي، وسند التفتيش.
- جرائم الأسلحة والذخائر: نوع السلاح، الصلاحية الفنية، الترخيص، السيطرة الفعلية، واستعمال السلاح في واقعة أخرى.
- جرائم الأسرة والطفل: سن الطفل، الصفة، الحضانة، التنفيذ، الخطر، وضمانات سماع الطفل.
- الجرائم الاقتصادية والمالية: القانون الخاص، الاختصاص الاقتصادي، التقارير الفنية، حركة الأموال، والتمييز بين النزاع المدني والجريمة.
- جرائم المال العام والوظيفة العامة: صفة الموظف العام، صلة المال بالجهة العامة، الاختلاس، الاستيلاء، التربح، الرشوة، والتقارير الحسابية.
- جرائم المرور والحوادث: صورة الخطأ، رابطة السببية، المعاينة، الرخص، التقرير الفني، والتقارير الطبية.

لم يتم تعديل Cloudflare Worker في هذه المرحلة.


## المرحلة 4.8 — مركز مراجعة جودة التكييف

تمت إضافة مركز مراجعة عكسي داخل غرفة تحليل الواقعة والتقرير الاحترافي. يقوم المركز باختبار التكييف المقترح من خلال: نقاط القوة، نقاط الضعف، الأسئلة الفاصلة، التكييفات البديلة، فجوات الدليل، والمراجعات الإجرائية، مع درجة جودة مبدئية وخطة عمل قبل الاعتماد.


## المرحلة 4.9 — محرك خطة التحقيق والاستيفاء العملي

تمت إضافة قسم عملي داخل غرفة تحليل الواقعة والتقرير الاحترافي بعنوان: **خطة التحقيق والاستيفاء العملي**.

يقوم القسم بتحويل التكييفات والقوالب ومركز جودة التكييف إلى خطوات عملية مرتبة تشمل:

- أسئلة المجني عليه.
- أسئلة المتهم.
- أسئلة الشهود.
- طلبات التحريات ومحاضر الضبط.
- التقارير الفنية والطبية.
- الأحراز والمستندات.
- مراجعة صحة الإجراءات.
- نقاط ما قبل التصرف النهائي.
- احتمالات التصرف بعد الاستيفاء.

الهدف أن ينتقل سَنَد من التحليل النظري إلى مساعدة عضو النيابة في ترتيب خطة تحقيق عملية قابلة للمراجعة.

## المرحلة 4.10 — مولد مسودة مذكرة التصرف والاستيفاء

أضيفت غرفة جديدة داخل نتيجة تحليل الواقعة لتوليد مسودات أولية قابلة للتحرير، ومنها:

- مذكرة استيفاء.
- طلب تحريات.
- أمر/طلب ندب خبير أو تقرير فني.
- ملخص اتهام مبدئي داخلي.

تظهر المسودات من زر **📝 مسودة التصرف** داخل نتيجة التحليل أو من زر **📝 مسودات التصرف** داخل التقرير الاحترافي. هذه المسودات للاسترشاد والمراجعة فقط، ولا تعتبر قرارًا نهائيًا أو صياغة ملزمة.

## المرحلة 4.11 — محرر المسودات القضائية الذكي

أضيف محرر مستقل للمسودات الناتجة عن غرفة تحليل الواقعة، يسمح بتعديل المسودة يدويًا داخل المنصة، وتطبيق أدوات صياغة مساعدة، وإضافة المواد المرتبطة، والنسخ والطباعة والحفظ المحلي.

لا يوجد أي تعديل مطلوب في Cloudflare Worker لهذه المرحلة.

## المرحلة 4.12 — قوالب أوامر وطلبات النيابة
تمت إضافة قوالب عملية جديدة إلى مركز المسودات، وتفتح جميعها داخل محرر المسودات القضائية الذكي:

- طلب فحص كاميرات / تسجيلات.
- أمر استعجال تقرير طبي أو طب شرعي.
- استدعاء شاهد / سماع أقوال.
- أمر تحريز / عرض حرز.
- طلب بيان من جهة إدارية.

القوالب الجديدة مبنية على ملخص الواقعة، خطة التحقيق، الأحراز، والأسئلة المستخلصة من نتيجة التحليل، وهي قوالب استرشادية قابلة للتحرير وليست أوامر نهائية.


## المرحلة 4.13 — توسيع مسودات التصرف والأوامر العملية

تم توسيع مركز المسودات ليشمل أنواعًا عملية إضافية من مذكرات التصرف والأوامر والطلبات، مع فتح كل مسودة داخل محرر المسودات القضائية الذكي.

تشمل الإضافات: مذكرة الحبس أو البدائل، إخلاء السبيل، إذن الضبط والتفتيش، الضبط والإحضار، الإحالة، الحفظ، ألا وجه، المعمل الكيماوي، فحص السلاح، بيانات الاتصالات، التصالح أو التنازل، وطلب صحيفة الحالة الجنائية.

كل المسودات تظل استرشادية وقابلة للتحرير وتحتاج مراجعة بشرية كاملة قبل الاعتماد.

## المرحلة 4.14 — فلترة المسودات حسب الواقعة
تم تنظيم مركز مسودات التصرف في تبويبات ذكية:
- المقترحة لهذه الواقعة
- استيفاءات وتحريات
- تقارير وفحوص فنية
- تصرفات قضائية
- شهود وأطراف
- أدلة رقمية
- كل المسودات

يعتمد الترشيح على مؤشرات الواقعة ونوع الجريمة وخطة التحقيق والقوالب المتخصصة.

## المرحلة 4.15 — تصدير التقرير والمسودات
تمت إضافة تصدير التقرير والمسودات إلى ملفات Word بصيغة HTML متوافقة مع Microsoft Word، مع دعم الطباعة والحفظ كـ PDF من نافذة الطباعة في المتصفح.

# المرحلة 5.1 — إعادة الهيكلة المؤسسية

تمت إضافة طبقة مؤسسية جديدة دون كسر النسخة التشغيلية الحالية.

## إضافات المرحلة

- ملف إعدادات مركزي: `config/app-config.js`
- سجل وحدات المنصة: `core/module-registry.js`
- نقطة تمهيد مؤسسية: `core/runtime/platform-boot.js`
- مجلدات Modules واضحة: `modules/`
- توثيق معماري وتشغيلي: `docs/`
- سياسة أمان وتخزين مبدئية داخل `core/security` و`core/storage`

## الغرض

تجهيز المنصة للانتقال التدريجي إلى لوحة إدارة، مستخدمين وصلاحيات، Backend مؤسسي، وسجل عمليات، دون تعطيل GitHub Pages أو أدوات سَنَد الحالية.


## المرحلة 5.2 — لوحة الإعدادات المؤسسية

تمت إضافة لوحة إعدادات داخلية من زر: **⚙️ إعدادات المنصة**.

تسمح اللوحة بتعديل:

- اسم المنصة والاسم المختصر واسم سَنَد.
- سطور التوجيه والإشراف والتطوير.
- رابط Cloudflare Worker ومسار live-token.
- صوت سَنَد الافتراضي ونمط الحوار الصوتي.
- تفعيل وتعطيل بعض المزايا.
- تصدير واستيراد الإعدادات كملف JSON.

تنبيه أمني: اللوحة لا تحفظ أي مفاتيح API. مفاتيح Gemini تظل داخل Cloudflare Secrets فقط.


## المرحلة 5.3 — لوحة إدارة القوانين والقوالب وسَنَد

أضيفت لوحة إدارة مؤسسية أولية باسم **إدارة المحتوى المؤسسي** تتيح إدارة سجل القوانين، وقوالب المسودات، وإعدادات شخصية سَنَد التحليلية محليًا عبر `localStorage`، مع تصدير واستيراد نسخة JSON تمهيدًا للربط لاحقًا بقاعدة بيانات وBackend مؤسسي.

> لا تحفظ اللوحة أي مفاتيح API أو بيانات قضايا حقيقية. الهدف هو إدارة المحتوى العام والقوالب المؤسسية فقط.

## المرحلة 5.4 — ربط الإدارة فعليًا بالمنصة

أصبحت لوحة إدارة المحتوى المؤسسي مؤثرة فعليًا في:

- مركز مسودات التصرف: تعطيل القوالب، إضافة قوالب جديدة، وترتيبها وفق كلمات ترجيحية.
- شخصية سَنَد: النبرة، مستوى الحذر، والتعليمات الإضافية أصبحت تدخل في تعليمات سَنَد النصية والصوتية.

التخزين الحالي محلي عبر `localStorage` تمهيدًا لنقله لاحقًا إلى Backend وقاعدة بيانات.

## Phase 5.5.5 — Professional Judicial Sign-up

This phase upgrades the membership registration screen into a professional judicial membership request form. It collects additional review fields such as judicial title, prosecution office, parent prosecution, district, official/work contact details, request reason, and requested access type. These fields are stored in `users.judicial_profile_json` after applying the D1 migration:

```powershell
wrangler d1 execute north_assiut_auth_db --remote --file=backend/d1/migration-5.5.5-judicial-profile.sql
```

The account remains `pending_approval` until reviewed and approved by the Super Owner/admin.

## Phase 5.8 — Professional Judicial Membership Review


## Phase 5.10 و 5.11 — الصلاحيات والسجل الأمني

أضيفت طبقة إنفاذ صلاحيات أمامية لتنظيم ظهور الشاشات حسب صلاحيات الجلسة، مع مركز مراجعة يوضح ما هو متاح أو محجوب للمستخدم الحالي. كما أضيف مركز أمن وسجل عمليات يعرض Audit Log من Auth API مع فلاتر وتصدير JSON ونسخة احتياطية محلية لإعدادات الواجهة.

## Phase 5.12 — مركز حسابي والجلسات وكلمة المرور

أضيفت شاشة **👤 حسابي** للمستخدمين المسجلين، وتشمل:

- بيانات العضوية والدور وحالة الحساب.
- مدة العضوية والأيام المتبقية.
- الصلاحيات الحالية.
- الأجهزة المسجلة والجلسات النشطة.
- تغيير كلمة المرور مع خيار إنهاء الجلسات الأخرى.

يتطلب تفعيل تغيير كلمة المرور والجلسات نشر ملف `backend/cloudflare-worker-auth-api.js` المحدث على Cloudflare Worker. لا توجد Migration جديدة مطلوبة.
