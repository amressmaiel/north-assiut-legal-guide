# الأسرار والخصوصية

## الأسرار

- لا تضع `GEMINI_API_KEY` في GitHub.
- المفتاح يظل في Cloudflare Worker Secrets.
- الواجهة تتعامل مع Cloudflare Worker فقط.

## بيانات الوقائع

- يجب تجنب إدخال بيانات شخصية حساسة قدر الإمكان.
- يفضّل استخدام أوصاف منقحة عند التجربة.
- أي تخزين مؤسسي لاحق يجب أن يكون بصلاحيات، وسجل عمليات، وربما تشفير.
