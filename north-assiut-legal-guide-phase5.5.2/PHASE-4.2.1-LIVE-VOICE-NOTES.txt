المرحلة 4.2.1 — الحوار الصوتي المباشر الاحترافي مع سَنَد
=====================================================

الإضافات:
- شاشة حوار صوتي مباشر مستقلة داخل غرفة تحليل الواقعة.
- إصدار Ephemeral Token قصير العمر من Cloudflare Worker عبر POST /live-token.
- اتصال مباشر منخفض التأخير بين المتصفح وGemini Live API عبر WebSocket.
- استخدام الموديل: gemini-3.1-flash-live-preview.
- إدخال صوتي PCM 16-bit بمعدل 16kHz ورد صوتي PCM بمعدل 24kHz.
- تفريغ نصي مباشر لكلام عضو النيابة وردود سَنَد.
- مقاطعة طبيعية لرد سَنَد عند بدء المستخدم الكلام.
- كتم الميكروفون وإنهاء الدور وإنهاء الجلسة.
- مراجعة النص قبل إضافته إلى وصف الواقعة.
- مسار احتياطي للتسجيل المحلي والمراجعة النصية.

مهم قبل التشغيل:
1. ارفع ملفات GitHub Pages كلها بنفس ترتيب المجلدات.
2. افتح ملف backend/cloudflare-worker.js وانسخ محتواه كاملًا مكان كود Worker الحالي في Cloudflare.
3. اضغط Deploy داخل Cloudflare.
4. تأكد من استمرار وجود Secret باسم GEMINI_API_KEY.
5. Rate Limiting Binding باسم SAND_LIVE_RATE_LIMITER اختياري ويمكن إضافته لاحقًا.

ملاحظات:
- لا يوجد GEMINI_API_KEY داخل GitHub أو ملفات الواجهة.
- المتصفح يحصل فقط على رمز مؤقت قصير العمر يصلح لجلسة واحدة.
- Gemini Live API وEphemeral Tokens ما زالا Preview وفق توثيق Google الحالي.
- يلزم اختبار عملي بعد النشر لأن إنشاء Token والاتصال الفعلي يحتاجان GEMINI_API_KEY وخادم Cloudflare المنشور.
- تمت إضافة زر «ناقش النتيجة صوتيًا» بعد ظهور تقرير تحليل الواقعة، ويرسل سياق التقرير إلى الجلسة الصوتية كمذكرة مراجعة داخلية قابلة للتحديث.
