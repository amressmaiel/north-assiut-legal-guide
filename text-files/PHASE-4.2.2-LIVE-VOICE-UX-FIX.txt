المرحلة 4.2.2 — إصلاح تهيئة الحوار الصوتي وتحسين واجهة المستخدم

التغييرات:
- إزالة اسم Gemini Live API وأي تفاصيل تقنية من واجهة المستخدم.
- إخفاء سجل خطوات WebSocket والرمز المؤقت من الشاشة؛ السجل أصبح داخل Console فقط للمطور.
- إضافة مهلة انتظار 15 ثانية لتهيئة الجلسة بدل بقاء الشاشة معلقة بلا نهاية.
- تبسيط رسالة setup المرسلة لخدمة Live API إلى الحد الأدنى المستقر.
- إضافة معالجة صريحة لخطأ الخادم وإغلاق WebSocket قبل اكتمال setup.
- عرض رسالة عربية بسيطة عند فشل الاتصال مع الإبقاء على المسار الاحتياطي.
- استخدام realtimeInput.text عند إرسال سياق مناقشة نتيجة سابقة بعد بدء الجلسة.

لا يحتاج هذا الإصلاح إلى تعديل Cloudflare Worker إذا كان مسار /live-token يعمل ويصدر الرمز المؤقت بالفعل.
