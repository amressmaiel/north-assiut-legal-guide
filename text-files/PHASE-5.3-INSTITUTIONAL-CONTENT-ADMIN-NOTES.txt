# PHASE 5.3 — Institutional Content Administration Panel

## المنجز
- إضافة زر: 🧩 إدارة المحتوى المؤسسي.
- إضافة لوحة إدارة للقوانين المحملة وسجل قوانين مضافة محليًا.
- إضافة إدارة أولية لقوالب المسودات: إضافة/تعديل/تعطيل/حذف محلي.
- إضافة إدارة لشخصية سَنَد: النبرة، مستوى الحذر، صيغة التنبيه، تعليمات إضافية.
- إضافة تصدير واستيراد JSON لمحتوى الإدارة.
- عدم تعديل Cloudflare Worker وعدم تخزين أي مفاتيح سرية.

## الحدود الحالية
- التعديلات محلية عبر localStorage.
- الدمج العميق مع مركز المسودات وقاعدة القوانين سيتم تدريجيًا في 5.4 وما بعدها.
- لا يتم تخزين بيانات قضايا أو أشخاص حقيقية داخل لوحة الإدارة.

## الاختبار المقترح
1. افتح القائمة الجانبية.
2. اضغط 🧩 إدارة المحتوى المؤسسي.
3. أضف قالبًا تجريبيًا ثم صدّر ملف JSON.
4. عدّل مستوى حذر سَنَد ثم احفظ.
5. استورد الملف مرة أخرى وتأكد من ظهور البيانات.
