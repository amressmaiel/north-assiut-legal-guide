# حدود التخزين

المرحلة الحالية تعمل بنمط Local-first داخل المتصفح. المرحلة 5.1 لا تنقل البيانات إلى خادم.

الخطة التالية:

1. تخزين إعدادات عامة وقوالب غير حساسة في Backend.
2. تخزين بيانات الوقائع اختياريًا فقط وبصلاحيات واضحة.
3. إضافة تصدير/استيراد ملف قضية مشفر في مرحلة لاحقة.
4. فصل بيانات القوانين عن بيانات المستخدمين.
