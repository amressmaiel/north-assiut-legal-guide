# سياسة الأمان الأولية للمرحلة 5.1

- لا يتم وضع مفاتيح Gemini أو أي مفاتيح API داخل ملفات الواجهة.
- Cloudflare Worker هو موضع الاتصال الآمن بالخدمات الخارجية.
- أي بيانات واقعة أو محادثة يجب أن تعامل كبيانات حساسة.
- التخزين الحالي Local-first، ومع الانتقال المؤسسي يجب إتاحة تشفير/صلاحيات/سجل عمليات.
- أي ملفات تصدير Word/HTML/PDF ينتجها المستخدم تكون مسؤوليته المهنية ويجب مراجعتها قبل الاعتماد.
