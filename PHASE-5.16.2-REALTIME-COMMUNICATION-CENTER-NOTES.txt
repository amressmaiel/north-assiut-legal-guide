المرحلة 5.16.2 — مركز التواصل القضائي الحقيقي والتطوير المتقدم

تم البناء على المرحلة 5.16.1 وإضافة طبقة تشغيل تجعل مركز التواصل جاهزًا للعمل الحقيقي بين أجهزة وأعضاء مختلفين بدل الاعتماد على نفس الجهاز فقط.

أولًا: طبقة Realtime Adapter
- إضافة ملف assets/js/secure-communication-realtime.js.
- إضافة إعدادات ربط داخل مركز التواصل القضائي.
- دعم وضعين للتشغيل:
  1) محلي آمن Local fallback عند عدم ضبط السيرفر.
  2) مزامنة حقيقية عبر Worker عند ضبط رابط خدمة التواصل.
- حفظ رابط Worker ومفتاح الربط واسم نطاق المنصة Workspace داخل إعدادات محلية.
- زر اختبار الاتصال.
- زر مزامنة الآن.
- مزامنة تلقائية بفواصل زمنية قابلة للضبط.
- عرض حالة الاتصال: محلي فقط / جار المزامنة / متصل / تعذر الاتصال.

ثانيًا: البيانات التي تتم مزامنتها
- الرسائل.
- طلبات التواصل.
- الزملاء الموثوقون.
- المجموعات والقنوات.
- الحظر.
- سجل التدقيق.
- إعدادات الخصوصية.

ثالثًا: Worker و D1
- إضافة backend/cloudflare-worker-comm-realtime.js.
- إضافة backend/d1/migration-5.16.2-communication-realtime.sql.
- يدعم Worker المسارات:
  /comm/ping
  /comm/sync
- يدعم COMM_SHARED_SECRET اختياريًا لتأمين الربط بمفتاح Bearer.
- يحفظ الأحداث في comm_events.
- يحفظ أحدث Snapshot لكل مفتاح في comm_snapshots.
- يدمج البيانات حسب معرفات السجلات وأحدث تاريخ تعديل.

رابعًا: تطوير الرسائل
- إضافة تثبيت الرسائل المهمة.
- إضافة إلغاء تثبيت الرسائل.
- إضافة تأكيد اطلاع على الرسالة.
- عرض عدد تأكيدات الاطلاع.
- إضافة بيانات مرفق أو رابط على الرسالة.
- تجهيز الأساس لمرحلة رفع المرفقات الفعلي لاحقًا.

خامسًا: التشغيل بين الأجهزة
- عند نشر Worker وضبط رابطه من إعدادات مركز التواصل، يبدأ الجهاز في رفع التغييرات وسحب أحدث التغييرات.
- إذا تعذر الاتصال، تظل المنصة تعمل محليًا ولا يتوقف مركز التواصل.
- عند عودة الاتصال يمكن المزامنة يدويًا أو تلقائيًا.

سادسًا: ملاحظات أمان
- الضيوف لا يدخلون مركز التواصل.
- الخصوصية وقائمة الزملاء الموثوقين تظل أساس المراسلة الفردية.
- يمكن تفعيل مفتاح ربط Worker عبر COMM_SHARED_SECRET.
- هذه المرحلة لا تعرض أسرارًا داخل الواجهة، والمفتاح المستخدم يظل إعداد ربط تشغيلي يمكن تغييره.

سابعًا: الخطوة التالية المقترحة
- ربط Worker بنظام Auth API للتحقق من هوية المستخدم وصلاحياته قبل قبول المزامنة.
- دعم رفع المرفقات فعليًا إلى R2 أو تخزين آمن.
- إضافة تقارير قراءة للإدارة للإعلانات الرسمية.
- إضافة دعوة أعضاء للمجموعات بصلاحيات أدق.
